# 定价页横向标签与小数显示（2026-09-18）

## 行为

- 管理员定价页分为「按档次定价 / 单模型定价 / 发布任务 / 价格与历史」，默认显示按档次定价。面板持续挂载，切换保留未保存表单和预览；手机标签可横向滚动，支持方向键、Home、End 和明确的焦点。
- 提交发布后切到任务标签；结果不确定时显示具体错误并读取最新任务。修复单模型成功发布后仍无条件触发不确定回调的问题。价格目录的定价按钮可返回档次标签。
- 参考价及已保存报价回填输入时，将机器精度内的明显浮点尾数（例如 `0.39999999999999997`）显示为 `0.4`。没有固定小数位截断，极小报价、有效高精度、空白和零保持原义。
- 未编辑的输入保留原始数值，避免仅改备注或重新预览造成隐式报价变化。该原值记录仅在客户端草稿使用，不进入成本配置 API。
- 不更改定价后端、发布任务格式、数据库、new-api 配置或生产价格。
