> 状态：进行中

## 1. 需求

定价页只保留能用的东西，删掉跑不起来的那条链路，让「改价」只有一个入口。

## 2. 为什么它跑不起来

- 持久化核验 `src/lib/newapi/persisted-pricing.ts` 只接受 `mysql://`（第 65 行），而生产 new-api 是 PostgreSQL 15。
- 它的调度器 `startPricingPublishScheduler` 要 `NEWAPI_PRICING_DATABASE_URL` 才启动，生产 `.env` 里**没有这个变量**，所以从未启动。
- 生产库三张发布表全空：`pricing_publish_jobs`、`pricing_publish_writes` 零行，协调器 `active_job_id` 为空（revision 125）。成本规则 0 行，纳管分组 0，售卖规则 0。

所以这条链路从未在当前生产环境执行过一次写入。

## 3. 现有四条写价路径

| 路径                                      | 状态                   | 处置   |
| ----------------------------------------- | ---------------------- | ------ |
| 定价页「现有定价」→ `pricing-simple.ts`   | **在用**               | 保留   |
| 售卖规则 → `pricing-rules/apply.ts`       | 已上线但未纳管任何分组 | 保留   |
| 客户专属倍率 → `user-tier-multiplier.ts`  | 在用（个别客户）       | 保留   |
| 签名发布链路 V1–V7 → `pricing-publish.ts` | 跑不起来               | **删** |

`pricing-sync.ts` 只读 new-api 写 Portal 目录，不改价，保留。
