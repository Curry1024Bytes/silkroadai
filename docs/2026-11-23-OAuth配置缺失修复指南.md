# OAuth 配置缺失修复指南

**状态**: 待 operator 完成
**日期**: 2026-11-23
**问题**: 生产环境 Google/GitHub OAuth 返回 `oauth_not_configured` 错误

---

## 问题描述

生产服务器 `/opt/silkroadai-portal/.env` 中 OAuth 相关变量配置不完整：

- `GOOGLE_OAUTH_CLIENT_SECRET` 和 `GITHUB_OAUTH_CLIENT_SECRET` 为空字符串
- 导致客户访问 `/api/auth/oauth/google/start` 时返回 `{"error":"oauth_not_configured"}`

## 已完成的修复

✅ 2026-11-23 已修复：

- Redirect URI 从 `localhost:3002` 改为 `https://llmroute.club`
- 从 `.env.prod.example` 填入了已知的 Client ID：
    - Google: `609354884573-vp6ccsbv79ltvvg62km0m2a2bddce054.apps.googleusercontent.com`
    - GitHub: `Ov23liVu0O3TY6C1hYpA`

## 待 operator 完成

### 1. 获取 Google OAuth Client Secret

前往 [Google Cloud Console](https://console.cloud.google.com/apis/credentials)：

1. 找到 OAuth 2.0 客户端 ID：`609354884573-vp6ccsbv79ltvvg62km0m2a2bddce054`
2. 点击该客户端 → 查看「客户端密钥」(Client Secret)
3. **验证「已获授权的重定向 URI」**必须包含：
    ```
    https://llmroute.club/api/auth/oauth/google/callback
    ```
    如果没有，添加它并保存

### 2. 获取 GitHub OAuth Client Secret

前往 [GitHub Settings > Developer settings > OAuth Apps](https://github.com/settings/developers)：

1. 找到 OAuth App：Client ID = `Ov23liVu0O3TY6C1hYpA`
2. 点击该应用 → 「Generate a new client secret」
3. **验证「Authorization callback URL」**必须逐字为：
    ```
    https://llmroute.club/api/auth/oauth/github/callback
    ```
    如果不对，更新它并保存

### 3. 更新服务器 `.env`

SSH 到生产服务器：

```bash
ssh llmroute-prod
cd /opt/silkroadai-portal
nano .env
```

修改以下两行（替换 `YOUR_SECRET_HERE`）：

```bash
GOOGLE_OAUTH_CLIENT_SECRET="YOUR_GOOGLE_SECRET_HERE"
GITHUB_OAUTH_CLIENT_SECRET="YOUR_GITHUB_SECRET_HERE"
```

保存后（Ctrl+O, Enter, Ctrl+X）。

### 4. 重启 Portal 容器

```bash
docker compose -f docker-compose.prod.yml restart portal
```

等待 20 秒让容器启动。

### 5. 验证

访问以下 URL，应该重定向到 Google/GitHub 授权页面（不再是 `oauth_not_configured` 错误）：

- Google: https://llmroute.club/api/auth/oauth/google/start
- GitHub: https://llmroute.club/api/auth/oauth/github/start

完整测试流程：

1. 访问 https://llmroute.club
2. 点击「使用 Google 登录」
3. 完成 Google 授权
4. 应该成功注册/登录并重定向到 Portal 主页
