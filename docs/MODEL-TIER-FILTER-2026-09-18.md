# 模型清单按档次筛选

## 功能范围

公开 `/models` 与客户工作区 `/workspace/models` 共用模型浏览器，在标题右上角增加「档次筛选」。默认「全部档次」，选择具体档次后仅显示该档次当前关联模型，并展示该档次的人民币售价。搜索可与档次筛选叠加；手机布局中筛选框位于标题下方。

模型来源改为 Portal 已启用目录模型与已登记的当前档次/渠道关联，和定价目录保持一致。new-api 继续承担路由与扣费；本次不修改其配置，也不导入、启用模型或发布任何价格。此前讨论的按档次整体设置倍率属于另外的定价工作台改造，本次只完成模型清单入口。

## 价格与隔离

- 仅读取平台租户、已启用模型及档次；校验渠道精确归属，忽略已退役关联和隐藏模型。
- 每个模型/档次只取已生效的最新目录售价。没有价格显示「未定价」，不借用其他档次价格，不展示成本草稿或未来价格。
- 输入、输出、缓存读取、缓存写入保持现有精度，零价与缺失价格分别处理。图片价格展示元/张。既有动态价格仅提供价格表入口，不冒充固定单价。
- 登录客户的专属倍率替换公共倍率，按同一比例换算所有价格项。未知身份上下文、无法核验专属倍率或异常价格均返回加载失败，不回退到公共价格。
- 页面按请求动态渲染，读取结果不跨客户缓存。浏览器仅收到模型名、档次标签与售价，不接收渠道 ID、内部计费组、客户 ID、成本或凭据。
