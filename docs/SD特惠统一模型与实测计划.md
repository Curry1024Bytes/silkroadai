## 收费验收

1. 先确认测试入口运行新代码，确认测试 Key 分组、预算余额及新旧模型的列表可见性。线上仍在使用旧版本时可准备隔离环境复用已配置渠道。
2. 按表逐个提交，每条任务进入终态后再发下一条。对参考图、参考音频、混合参考各至少覆盖一次。1080p 带参考视频单独验收。请求超时先按任务 ID 或请求 ID 找原任务。
3. 逐项记录对外模型、内部 SKU、任务 ID、参考类型、请求秒数、成片分辨率及视频轨时长、Portal 实扣及上游最终实扣。生成终态和 MP4 下载分别验收。
4. 用旧分辨率 ID、官方版 ID、限时特价 ID 和非 `sd-2.5` 的 1080p 请求验证拒绝行为。检查这些请求没有创建任务或发生扣费。

历史 31 个内部型号的成绩见 [SD 特惠视频验收记录](./SD特惠视频验收记录.md)。
