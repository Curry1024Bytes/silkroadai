# 售价倍率输入优化与发布记录（2026-09-16）

## 改动与操作

用户希望将上游 1.3 倍直接加到售价 1.6 倍，不再手算加价百分比。本次把成本工作台的「在成本上加价（%）」替换为「我的售价倍率」，单项和批量操作使用同一语义：

- 基础报价尚未包含倍率：上游倍率填 `1.3`，我的售价倍率填 `1.6`；页面显示「加 0.3 倍」。
- 成本 = 基础报价 × 上游倍率 ÷ 每元到账额度；售价 = 基础报价 × 我的售价倍率 ÷ 每元到账额度。
- 人民币报价不做额度换算。若所填报价已经包含上游 1.3 倍，则上游倍率填 `1`，售价倍率也以这份已含倍率的报价为基准；此时再填 `1.6` 表示在这份报价上乘 1.6，不能理解为原基础报价的最终 1.6 倍。要直接填写原基础的 `1.3 / 1.6`，须先使用不含倍率的基础报价。
- 售价倍率不得低于上游倍率。保存只记录成本规则与版本；客户售价仍需经过预览、确认发布及核验后生效。
